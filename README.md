# 📚 Student Grade Tracker (Java)

A console-based Java application to manage student grades.  
Built as part of **CodeAlpha Internship – Task 1**.

---

## 🚀 Features
- Add students with name and grade
- Calculate average, highest, and lowest scores
- Assign grade categories (A–F)
- Save reports to a text file (`GradeReport.txt`)
- Interactive menu-driven interface
